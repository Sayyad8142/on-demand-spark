## Isolation protocol
`tests/run_offline.py` reviews the seven-file import graph, rejects capability/dynamic imports, copies only those files into a temporary directory and starts Bun without inherited environment/config/preloads. Environment contains only PATH/HOME/TMPDIR pointing to local runtime/temporary storage; no application imports or external dependencies. Linux x86_64 seccomp blocks socket transports and io_uring, with an independent socket-denial positive control required BEFORE tests. Actual run printed NETWORK_DENIAL_VERIFIED, then the scrubbed-graph marker, then the results. Unsupported kernel/architecture/scanner denial stops execution. This is reviewed-source containment plus kernel network denial, NOT a full filesystem isolation sandbox: process has ordinary OS file permissions, so the restricted reviewed graph/no file capabilities is part of the safety assurance. No credential file is read by the runner/tests; no install or service call occurs.

## Phase 5 executed coverage and limits
Boundary predicates test inclusive lower/exclusive upper at 30/90/14/7 days; R/Q/J additionally exercise calculator behavior at lower-boundary ±1ms. R/Q evidence exactly at the lower boundary has zero decay mass, although canonically included. The 14-day checks are only a predicate: availability scoring remains locked at 6. Success mass saturates at 20, fault mass at 5 separately; Q cap at 50. Pure tuples do not prove database race safety. Persistent onboarding milestones and complete independent arithmetic reference are NOT executed.
